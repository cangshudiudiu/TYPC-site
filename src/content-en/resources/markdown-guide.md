Markdown works well for blogs and reference material because it is lightweight and easy to move between systems.

## Common Patterns

- Use `#`, `##` and `###` for headings
- Use `[text](https://example.com)` for links
- Use backticks or fenced blocks for code
- Put downloadable files in the `public/files/` directory
